| ID | Title | Task | Idea | Tier |
|---|---|---|---|---|
| 2021-A | Omicron Juice | Equalise three glasses by moving single units. | Each move takes one unit from a glass and gives it to another, so the total never changes. At the end all three glasses are equal, so the total must split into three equal parts. Peaceful iff (A+B+C) mod 3 == 0, because any imbalance can be fixed one unit at a time. Both samples match. | 1 |
| 2021-B | Omicron Juice Again | Equalise three glasses moving K units at a time. | Moves now carry K units, so each glass changes only by multiples of K. The target is S/3 for every glass, so S must be divisible by 3 and every glass must differ from S/3 by a multiple of K. Those two conditions are enough (I checked them by BFS for small values). Use fast I/O because T goes up to 200000. | 2 |
| 2021-C | Bitonic Beaver | Count permutations compatible with k given permutations (bitonic condition). | Look at the sequence P[Q[1]], ..., P[Q[n]]. Bitonic means that for every value v, the positions holding values >= v form one contiguous block. So you add elements one at a time from the largest value, and every prefix set must be an interval in all k orderings at once. Counting such orders means working with the common intervals of k permutations (PQ-tree style). Too heavy; skip. | 5 |
| 2021-D | Lazy Squirrel | Fraction of tree nodes whose root path spells a palindrome. | The root-to-X path is a string and X is happy when it is a palindrome. You need to test that for every node in O(1). Keep a forward hash F = F_parent*B + c and a reverse hash R = R_parent + c*B^depth along the path. The path is a palindrome iff F == R. N is up to 1e6, so use an iterative DFS or BFS and a 64-bit modular hash (for example mod 2^61-1). Count good nodes g and print g/N reduced by gcd. | 3 |
| 2021-E | Pairdrome | Count palindromes that are a substring of X followed by a substring of Y. | A pairdrome is a palindrome T = x + y where x is a substring of X and y is a substring of Y. Look at the longer of x and y: the palindrome's centre lies inside it, and the other part must equal the reverse of the matching end. Counting such pairs correctly needs palindromic trees or suffix structures on both strings. Heavy; skip. | 5 |
| 2021-F | A Lonely Queen | Cheapest queen route with per-direction costs, obstacles and one-way tunnels. | Moving k steps in one direction costs the same C_d for any k, so a slide is one edge, but each direction can have O(n+m) targets. Avoid listing targets: use states (cell, direction). Start a slide: cell -> (cell, d) costs C_d. Continue: (cell, d) -> (next cell, d) costs 0 unless blocked or off the board. Stop: (cell, d) -> cell costs 0. Add the p one-way tunnels as ordinary edges and run Dijkstra on about 9*n*m <= 9e5 states. The answer is the distance to D, or -1. Since sum of n*m <= 1e5 this is fast. | 4 |
| 2021-G | Alice, Bob and Tree | Choose the root maximising an alternating-sign weight formula. | Since a tree is bipartite, (-1)^dist(root,i) is +1 for nodes in the root's colour class and -1 for the other class. So value(root) = W_root*(cnt_same - cnt_other) - (W_same - W_other), where 'same' means the root's class. Two-colour the tree once, precompute class counts and weight sums, evaluate every root in O(1), and keep the best with the smallest label. Checked against brute force. | 3 |
| 2021-H | Update Query Problem | Distinct strings from prefix of P-range plus suffix of Q-range under range-assign updates. | The query counts distinct strings X+Y with X a prefix of P[L1..R1] and Y a suffix of Q[L2..R2]. | 2021-I | Hovercraft | Shortest route over a river with a land/water rule (statement uses a figure). | The statement relies on a figure. | 2022-A | A Game with Grandma | Impartial 2x2-painting game on a 3xN grid with broken cells. | It is a two-player impartial game without draws, so think Sprague-Grundy. Notice that every 2x2 block uses the middle row in two neighbouring columns. So only the middle row matters: a move picks two neighbouring columns whose middle cells are good and whose top pair or bottom pair is good, and kills both columns. Columns form paths and a move deletes two adjacent vertices of a path (Dawson's Kayles). Split the board into maximal runs of columns joined by playable pairs. For a run of m columns g(m) = mex over a+b = m-2 of g(a) xor g(b), with g(0)=g(1)=0. XOR the runs: non-zero means Jhinuk. O(N^2) table. Check: 3 columns give 1, and 5 columns with a broken middle cell give 1 xor 1 = 0. | 3 |
| 2022-B | Transform the Array | Can Alice (per-element multiply/divide by a divisor of any element) or Bob (scale all elements together) turn A into B? | Alice may take D from any element, so primes can move between elements. What can never appear from nothing? Alice: every prime in every B_i must already appear in some A_j. Bob: he scales the whole array by divisors of the common gcd, so the ratios between elements never change. Bob: need A_i/gcd(A) = B_i/gcd(B) for all i, and every prime whose exponent in gcd(B) exceeds the one in gcd(A) must already divide gcd(A). Sieve smallest prime factors to 1e7 and factor the gcds. | 3 |
| 2022-C | Omago Virus | Expected days until everyone is infected when each infected person infects k random others daily. | Let E[i] be the expected days from i infected people to n. The state is only i, so it is a DP over i with a self-loop. For the transition i to j, choose which j-i people become newly infected and use inclusion-exclusion on the event 'all new infections fall inside a set T of size t'. That has probability (C(i-1+t, k) / C(n-1, k))^i because each of the i infected people picks k others. P(i->j) = C(n-i, j-i) * sum_t (-1)^(j-i-t) C(j-i, t) q(t). Then E[i] = (1 + sum_{j>i} P(i,j) E[j]) / (1 - P(i,i)) mod 998244353. O(n^3) fits n <= 400. The samples give 7/3 and 1. | 4 |

Peaceful iff the total is divisible by 3, every glass differs from the target by a multiple of K, and (all equal already or at least two glasses are at least K). | 3 |

| 2022-G | Portals and Roads | Choose exactly R roads and zero-cost portals forming a tree to minimise total distance from node 1. | With R roads you get N-R groups of consecutive nodes joined by roads; groups are tied together by portals. Node 1's group costs sum(D_i - D_1). Any other group is entered by a portal at its median node, costing sum \|D_i - D_median\|. dp[b][i] = best cost for the first i nodes in b groups, with prefix sums for O(1) group cost. | 2022-H | Mr. Dumb the Police in charge | Simulate a police officer who always serves the nearest pending request on a tree (ties by earliest time). | It is a simulation: the next target is chosen only when the police becomes free. At that moment take all requests with T <= now and pick the one minimising (distance from the current city, request time). | 2022-I | Image Cropping | Largest integer rectangle with a fixed aspect ratio centred at a pivot inside a convex quadrilateral. | The pivot is the exact center, so the rectangle is (px +- w/2, py +- h/2) with w:h = W:H. A centered rectangle shrinks inside a convex region, so binary search the largest v by testing the 4 corners with cross products. Use __int128, since v can reach 1e8 and W, H up to 1e5. | 4 |

| 2023-A | Almost Perfect Prime Factor! | Longest subarray with exactly K almost-perfect prime factors and no perfect one. | A prime is perfect for a subarray if it divides every element and almost perfect if it divides some but not all. 'No perfect prime' simply means the subarray gcd is 1. So find the longest subarray with gcd 1 and exactly K distinct primes. Distinct primes only grow as the window widens; gcd only shrinks. Factor values with a smallest-prime-factor sieve (<= 1e6). For each r keep the leftmost l with at most K distinct primes (two pointers with counts). Accept it if it has exactly K and gcd(l..r) = 1 (sparse table). Both samples reproduce. | 3 |
| 2023-B | Bob and Numbers | Sum over i<=N of \|i mod A - i mod (A-1)\| for N up to 1e12, A up to 1e5, 1e5 tests. | Write i = qA + r with 0 <= r < A. Then i mod A = r and i mod (A-1) = (q + r) mod (A-1), because A is 1 mod (A-1). So the term is \|r - ((q+r) mod m)\| with m = A-1. For a fixed q (let t = q mod m) the values r = 0..m give t for the first m-t of them and m-t for the rest, so one block sums to 2t(m-t) + (m-t). Sum over full blocks using the period m and closed-form sums of t(m-t), then add the partial last block r = 0..N mod A. O(1) per test. Checked against brute force. | 4 |
| 2023-C | Counting Ones II | Count ones in ranges of the row-major string of a K-times scaled N x N binary matrix. | Do not build the scaled matrix (N^2 K^2 can be 1e18). Define ones(pos) = number of ones in the first pos characters; answer = ones(R+1) - ones(L). One scaled row has N*K characters and each original row appears K times as scaled rows. Precompute per-row prefix sums and prefix sums of row totals. With f full scaled rows and c leftover characters, i = f / K: ones = K^2 * (sum of row totals before i) + (f mod K) * K * rowTotal[i] + K * P[i][c / K] + (c mod K) * cell[i][c / K]. Use fast I/O. | 3 |
| 2023-D | Sequence | Count distinct sequences of prefix lengths of P that can end at increasing positions in Q. | Matching prefixes of P in Q is the KMP automaton: at each end position the valid lengths are the border chain of the current state. Count distinct sequences by always assigning the earliest possible end index: dp[y] = sum over lengths x in the chain of (1 + prefix of dp from the previous occurrence of x to y-1). Maintaining the previous occurrence of every border length is a path assignment on the failure tree (heavy). Skip. | 5 |
| 2023-E | Sub-Array | Count subarrays that are not all equal. | Count the opposite: subarrays whose elements are all equal. Total N(N+1)/2 minus the sum over maximal equal runs of L(L+1)/2. One pass, 64-bit. Sample: 10 - 4 = 6. | 1 |
| 2023-F | Mesmerizing Fireflies | Min-area triangle (base on x-axis) over points, ratio to min bounding rectangle. | The rectangle is easy: width = maxx - minx, height = maxy. | 2023-G | Bowling Figure | Format overs, runs and wickets from a ball string. | balls = length, wickets = count of 'W', runs = sum of digits. overs = balls / 6 and the extra balls = balls % 6, printed as X.Y.
